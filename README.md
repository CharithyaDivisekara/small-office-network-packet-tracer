Small Office Network Design and Configuration

Project Overview

This project demonstrates the design and configuration of a small office network using Cisco Packet Tracer.
The office has three departments: Administration, Finance, and IT. Each department uses a separate VLAN to organize network traffic.

Objectives

    Create separate VLANs for three departments.
    Configure inter-VLAN routing using Router-on-a-Stick.
    Configure DHCP for automatic IP address assignment.
    Configure switch access ports and a trunk link.
    Test connectivity and troubleshoot network issues.

Network Topology
The network consists of:

    Cisco 2911 Router
    Cisco 2960 Switch
    6 PCs
    3 VLANs
